Guardrails, in my own words
Edited 14 minutes ago · Project · 412 words

The point of the rules is not that the model is untrustworthy. It is that a rule which can be talked out of is not a rule, and a rule that only holds in a solo session is not a rule either — a group chat is exactly where one agent would ask another to do the thing neither is allowed to.

What I keep having to re-explain

  • Installing a skill is not the same as trusting it. Grants are per agent for a reason.
  • Folder access is granted per folder, but every read is still listed afterwards. The grant is not a blank cheque.
  • Nothing about the rules is a setting. There is no switch, and the absence of a switch is deliberate.

The one I got wrong at first

I assumed the interesting failure mode was an agent refusing something it should allow. It is the opposite: the interesting failure is an agent quietly allowing something because the request was phrased as a role-play. That is why identity is its own rule rather than a footnote under safety.

Open question

Keyword matching for E9002 is still doing more work than it should. A classifier catches phrasing that a keyword list never will, but it also costs a call per message — worth measuring before deciding.
