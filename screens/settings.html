Settings

Appearance

Theme
Following the system is the default. Both themes are designed together and neither is a stripped-down version of the other.
Text size
Scales every size in the interface together, not just body text.
Reduce motion
Follows the system setting already. This forces it on regardless.

Language

Interface language
Independent of the system language. Where a translation is missing, the English string is shown rather than a blank or a key name.

Instructions

Added to every agent's context, on top of whatever its role template says. It cannot override the guardrails, and an instruction that tries to is ignored rather than silently obeyed.

Data

Data folder
Conversations, agents, memory, notes, keys and skills all live here. Moving it moves everything, and the app migrates the contents rather than starting empty at the new location.

Backups
There are none, by design — the app stores nothing off this machine and syncs nothing. Point your own backup tool at the folder above.
Erase all local data
Removes every session, agent, note, grant and key. There is no backup and no undo, because there is nowhere else a copy could exist.
