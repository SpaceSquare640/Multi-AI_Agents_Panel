Skills

Skills are Python programs that run in their own process, outside the app. Each one declares the permissions it needs, and holds none of them until an agent is granted the skill — installing is not the same as trusting.

A skill with no grants cannot run Grants are per agent, not global. An agent can only call the skills it has been given, which is what keeps one agent's tools out of another agent's reach.
