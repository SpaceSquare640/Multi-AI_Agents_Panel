Dialogs

Interruptions, and the rules they follow.

Every dialog here is a native <dialog>. Focus trapping, Esc, inertness of the page behind and the backdrop all come from the platform rather than from hand-written JavaScript, because a hand-written version of any of them is only ever a worse version. Focus opens on the least destructive control, so a stray Enter cannot confirm something irreversible.

Authorisation

Guardrails require file access to be granted explicitly, so this cannot be a toast that fades or a checkbox buried in settings — it has to be a decision the user actively makes, with the exact scope of what is being granted visible before they agree.

Grant folder access

Names the agent, the folder, and what it will be able to do — before the grant, not after.

Skill permissions

A skill declares scopes; granting one to an agent shows exactly which, including network reach.

Destructive confirmation

Two different treatments, chosen by whether the action can be taken back. A recoverable delete confirms lightly and offers undo afterwards; an unrecoverable one states what is lost and makes the confirming control wait until the name has been typed. Applying the heavier treatment to everything is how people learn to click through it without reading.

Delete a session

Recoverable for a few seconds. Confirms once, then offers undo in the toast.

Erase all local data

Unrecoverable. Lists what goes, and the confirm stays disabled until the phrase is typed.

Guardrail interception

When a rule stops something, the dialog says which rule and why rather than failing silently or blaming the model. It carries the error code so the behaviour can be looked up or reported, and it does not offer a way to proceed anyway — these rules have no user override, and pretending otherwise would be dishonest.

Error with a code

Every failure surface carries its code so it can be searched and reported.

Toasts

Announced politely and never given focus. Hovering pauses the countdown so one cannot expire while it is being read, and anything offering undo lives longer than the default because five seconds is not enough to read a message and change your mind.

Command palette

Press Ctrl K. Matching is by subsequence, so nsc finds “New solo session”; results are ranked so the obvious answer sits under the cursor. Arrow keys move the selection without moving focus out of the input, and closing returns focus to whatever opened it.
