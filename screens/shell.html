App shell

The frame every screen is built inside

A rail of destinations grouped into workspace, capabilities and system; a sidebar whose contents follow the rail; the workspace itself; and an inspector for whatever the workspace is currently about.

Drag a seam to resize a side panel, or focus one and use the arrow keys. The rail is a toolbar, so arrow keys move between destinations there too. Ctrl K opens the palette.

Inspector
What goes here

Agent configuration, guardrail state, tool calls and live spend — whatever the workspace is about, in detail. Screens with nothing to inspect hide this panel rather than showing an empty one.
