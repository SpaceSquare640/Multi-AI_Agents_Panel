Multi-AI Agents Panel

UI design source of truth

A static HTML/CSS/vanilla-JS mockup of every screen in the desktop app. Nothing here is compiled, imported or shipped — designs are settled here first, then ported into the React components on the Source_Code branch by hand. Every page reads from the same token file, so switching the theme above changes all of them at once.

These are mockups of a desktop application, laid out for a window rather than a phone. On a narrow screen the panels collapse and the frame gets cramped — that is the design working as intended, not a broken page.
